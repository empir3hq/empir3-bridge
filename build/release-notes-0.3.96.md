Empir3 Bridge 0.3.96 is the unified desktop and headless release for Windows, macOS, and Linux.

Highlights:

- Isolates controlled-browser profiles by Empir3 account and retires the old device credential during account re-pairing.
- Makes installed CLI update, authentication, installation, and sign-out results visible, with safe diagnostic details on failure.
- Adds a scoped Windows wake and keep-awake path for controlled-browser work without bypassing the secure desktop.
- Restores Antigravity model discovery for tab-separated CLI catalogs.
- Keeps z.ai Coding Plan credentials on their dedicated endpoint and separate from ordinary z.ai API keys.
- Pins Codex tool routes to the private Empir3 MCP attachment contract and refuses to run a tool turn without it.
- Includes the 0.3.95 three-way project-sync and conflict-sidecar protections for every newly installed or updated machine.

All native packages must complete the Windows, macOS, Linux x64, Linux ARM64, Node 18/20, installer, update, rollback, signing/notarization, MCP, and live Bridge acceptance gates before publication.

Download the signed installer for your platform at https://empir3.com/download.
